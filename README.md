# ENDLESS WALK

街並みを延々と歩き続けるのを眺めるアプリ。そのまま MP4 に書き出せる。
[ENDLESS DUNGEON](https://haristweet.github.io/endless-dungeon/)・[ENDLESS FLIGHT](https://haristweet.github.io/endless-flight/) の姉妹作で、書き出し・音・歌詞の仕組みは共通。
`index.html` と同梱の `mp4-muxer.js`・`opus-decoder.min.js` だけで動く（ビルド不要）。

## できること

- 街並み5種を順に巡る（選んだものだけ。2分ごとなどで暗転して「2つ目の街」と出る）
  - 住宅街と商店街：電柱と電線、ブロック塀、切妻屋根の家、自販機。ときどきアーケードの商店街
  - 杜の都・仙台：ケヤキ並木の大通り（定禅寺通ふう。真ん中の緑地帯を歩く。夜は光のページェントの電球が灯る。ときどきメディアテークふうのガラスの建物）、七夕飾りのアーケード（ガラス屋根の下にくす玉と吹き流し）、国分町の夜の路地、広瀬川の橋（段丘の崖のあいだを渡る）が入れ替わる。場面の変わり目は横断歩道と信号の交差点
  - 石畳の旧市街：色とりどりの壁、鎧戸と窓辺の花、日よけ、壁の灯り。ときどき噴水と教会の塔のある広場
  - ネオン街：光る縦看板と横看板、赤い提灯、水たまりに映る色
  - 坂の港町：上り下りする海沿いの道、手すり、白い家の段々、船と灯台
- 時刻がゆっくり移り変わる（朝→昼→夕方→夜）。夕方から窓と街灯が灯り、夜は星が出る
  - 一日の長さ：4分 / 8分 / 16分、歩き始める時刻：朝・昼・夕方・夜
- 描き方：ポリゴン / 線画、視点：歩く人の目線（歩みに合わせて少し揺れ、ときどき脇を見る）/ 後ろから（手足を振って歩く人）
- 画面の飾り（あり：地図・散歩の記録〈時刻・歩数・距離・街〉・つぶやき欄）
- 画素の粗さ、速さ（ゆっくり・ふつう・早歩き）、道の番号（シード。同じ番号なら同じ道のり）
- MP4書き出し：640×480〜1920×1080、「3:19」のような長さ指定、30 / 60コマ/秒、音と歌詞（つぶやき欄か字幕に流す）
- 終わり方（曲を入れたとき）：車に跳ねられる（既定）/ そのまま歩く。跳ねられるのは曲の終わり（書き出しの長さの終わり）の2.6秒前で、3.6秒前から前方に車が見え、クラクション・急ブレーキ・ぶつかる音が鳴る。目線では回りながら仰向けに倒れ、後ろからでは体が飛ぶのを引いて見下ろす。赤く染まって暗転し「BAD END」

## しくみのメモ

- **道**：正弦波の和で左右にゆるく曲がる道（港町は上り下りも）。長さ30mごとの区切りを、番号・街・区切りの番号から決まる乱数でその場で組み立てる。建物は道に面して並べ、区切りをまたがないよう最後の1棟を詰める。
- **時刻**：時刻ごとの空・地平線・光の色・環境光・「夜らしさ」の表を滑らかにつなぐ。窓や街灯は「夜に灯る」印を持ち、昼は暗いガラス、夜は光る色になる（夜らしさで混ぜる）。看板などは「いつも光る」。
- **描画**：ENDLESS FLIGHT と同じ WebGL2 の仕組み（重心座標で辺を線にする・線画は面を黒く塗って隠れ線処理）。
- **書き出し・音・歌詞**：ENDLESS DUNGEON / FLIGHT と同じ。
- **バッドエンド**：`CRASH`（車が見える秒・跳ねる秒・車の速さ）と `Sim.crash()`・`thrown()`。跳ねられたら歩みは止まり、終わりの8秒前より後には街を変えない（暗転と重ならないように）。音は `crashSfx()` で作り、書き出しでは曲の上に重ねる。プレビューでは終わって2.5秒で最初から。
- ローカル確認：`python3 -m http.server 8801`
- 絵の確認：サーバーを立てて `node test/shots.mjs 出力.png`（無音の曲を入れて、バッドエンドの前後を目線・後ろから・線画で一覧にする）
